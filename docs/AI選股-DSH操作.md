# 在 DSH 對話框用「目前模型」選股（操作說明）

> 適用：你想讓 **DSH 這個對話視窗裡的模型**直接當選股模型，不想另外申請 API 金鑰。
> 換模型＝在 DSH 裡換模型，程式與資料都不用改。
> 工具：`scripts/ai_pick_dsh.py`（產生封包／prompt、驗證並落地模型回答）

---

## 你只要做一件事：貼日期

在這個對話框貼上任一種寫法即可（其餘交給助理）：

```
2022-01-03 選股
```
```
選股日 2022-01-03，池 50，取 5
```
```
2022-01-03 top5（每月換股的 D1）
```

可選參數（沒寫就用預設）：日期（必填）、候選池大小（預設 50）、取幾檔（預設 5）、
要不要含新聞（預設不要，因為很貴：一檔一天一次呼叫）。

---

## 助理會做的四步（每步都可稽核）

| 步 | 動作 | 產出 |
|---|---|---|
| 1 | `scripts/ai_pick_dsh.py --as-of <日期> --pool-n 50 --top-n 5 --emit prompt` → 重建**當時**的誠實池（當時市值前 N）與 point-in-time 封包 | `logs/ai_pick/<日期>/pack.json`＋`prompt.txt`（含 sha256） |
| 2 | 助理**只依封包**作答：5 檔＋每檔 2~3 條理由＋引用 `[R#]`，輸出 JSON | 對話中的 JSON |
| 3 | `scripts/ai_pick_dsh.py --as-of <日期> --top-n 5 --picks '<JSON>' --model "dsh:<模型名>"` → `parse_selection` 驗證（不得新增標的／數量要對／引用必須是 `R#`） | `response.json`＋`audit.json` |
| 4 | （可選）`scripts/ai_pick_ab.py --start <日期> --end <日期> --pool-n 50 --top-n 5 --reuse` → 把這次選股納入「AI vs 純規則」統計 | `results/ai_ab_*.json` |

第 3 步會擋掉：自行新增池外標的、檔數不符、沒有引用、引用不是 `R#`（例如模型用「我記得…」）。
第 1 步的 `assert_no_lookahead()` 會擋掉任何晚於選股日的資料。

---

## 給模型看的 prompt（第 1 步產生的就是這份）

```
你是台股量化選股助手。你只能使用下面「本次資料」裡的內容，
不得引用任何資料之外的記憶、事件或未來已知的結果。若資料不足以判斷，就明說不足。

硬規則：
1. 只能從候選清單挑選，不得新增、不得替換代號。
2. 每一檔必須給 2~3 條理由，且每條理由都要標註引用的資料編號（例如 [R3]）。
3. 不得使用任何 2022 之後的事件知識（例如某人某檔後來大漲/大跌）。
4. 只輸出 JSON，不要任何其他文字，格式：
   {"as_of": "<日期>", "picks": [{"sid": "...", "reasons": ["... [R1]"], "citations": ["R1"], "risk": "..."}]}

選股日：<日期>

【本次資料】
[R1] 2330：收盤 581.55｜20日報酬 0.0426｜63日報酬 0.1082｜距52週高 -0.0544；PER 28.55（2022-01-03）
    （注意：[R1] 沒有月營收資料，不得臆測）
    （注意：[R1] 沒有新聞資料，不得臆測）
…
請從上列 N 檔中選出 K 檔，並依規定格式輸出 JSON。
```

封包欄位（各檔）：`close`、`ret_20d`、`ret_63d`、`dist_from_252d_high`、`per`（含日期）、
`inst_net_15d`（法人近 15 日淨買超）、`month_revenue`（YoY／MoM，**用次月 10 日判斷當時看不看得到**）、
`news`（到秒時間戳，**只採用到選股日 13:30**）。缺的資料一律標 `unavailable`／`null`，不得臆測。

## 換模型（你唯一要記得的事）

1. 在 DSH 介面切換模型（這是唯一「換 AI」的動作）。
2. 告訴助理「這次用 `<模型名>`」，或助理會在落地時把 `--model` 標成你當下的模型；
   `logs/ai_pick/<日期>/audit.json` 會記 `model`，所以**不同模型的選股不會混在一起**。
3. 想比較兩個模型：同一天各跑一次（換模型→再貼一次日期），兩份 `response.json` 分別落地，
   再用 `ai_pick_ab.py --reuse` 或其他比較工具對照。

> 若你偏好「程式自動叫模型」而不是手動貼：`scripts/llm_cli.py` 支援 `--provider ollama`（本機、免費）
> 與 `--provider openai`（任何 OpenAI 相容 API，金鑰只放環境變數），用法見 `cairn/ai-stock-selection.md`。

---

## 誠實限制（每次看結果都要記得）

1. **模型的記憶無法被證明沒有先見之明**：本流程能保證的是「**餵給模型的資料**沒有未來資訊」＋全程可稽核；
   不能保證模型沒用訓練語料裡的未來知識。所以這些選股是**假設**，不是證據。
2. **要當證據需要 A/B 樣本**：同一日期、同一池，AI 選股 vs 本專案規則選股，累積 ≥30 個選股日再看 t 值
   （`scripts/ai_pick_ab.py`；`--require-full` 可要求兩邊都選滿 N 檔）。
3. **規則組與 AI 組的籃子可能不同大小**（規則組的過熱濾網可能只選得出 2~3 檔）⇒ 非嚴格模式下比的是
   「實際會持有的籃子」。
4. 法人資料快取目前只有 41 個交易日、月營收沒有公告時間（用法定期限估算）、新聞預設關閉 ⇒
   封包常是「價格＋PER」為主。資料越薄，模型的判斷越接近瞎猜。
