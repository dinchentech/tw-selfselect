## 核心觀念
1. **閉環流程**：調整參數 → 跑回測 → 看結果 → 再調整 → 確定參數 → 寫進 `.env` → 模擬帳觀察 → 才考慮真錢。
2. **回測是便宜的實驗室**：實盤下錯單會賠錢，回測錯了重跑就好。
3. **零成本的順序永遠是**：
   `backtest.py` 回測 → `ESUN_ENVIRONMENT=simulation`（玉山模擬帳）→ `ESUN_ENVIRONMENT=real`（真錢）。
   切 `real` 之前，請完整走過 `使用手冊.md` §8「真錢上線檢查清單」。
4. **本專案的兩條硬規則**（八年級生最容易踩）：
   - 只有**程式碼**真的被改動時，才把 `core/version.py` 的 `APP_VERSION` +1；只改 `.env`、報告、文件**不要**動版號。
   - 部署一律由你本人手動執行 `./deploy_source.sh`，AI 不會代跑。版號會出現在啟動 banner、Telegram 與儀表板，換版後一眼可確認。
5. **八大觀念回顧**：

```
第 1 週：變數與型態   → 你知道參數值是數字還是文字
第 2 週：DataFrame    → 你知道 df['close'] 在取什麼
第 3 週：條件判斷     → 你讀得懂買賣條件
第 4 週：rolling      → 你知道為什麼要暖身、為什麼資料要給足
第 5 週：四大策略     → 你能指出買在哪、賣在哪，參數在哪裡調
第 6 週：主程式       → 你知道 selfselect_trader.py 一天怎麼跑、每月 D1/D2 在做什麼
第 7 週：AI 改程式    → 你學會跟 DSH 對話
第 8 週：整合         → 你能完成一次完整的修改！
```
