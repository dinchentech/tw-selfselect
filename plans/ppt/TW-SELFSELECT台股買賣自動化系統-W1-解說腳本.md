## slide-5 系統簡介（2 分鐘）

接下來介紹系統本身。這套系統最大的設計理念，就是「為非資訊背景的人設計」。
首先，每個雲端主機一個月的費用不到一百塊台幣；每個主機可以控制十五檔以內的個股。程式會自動開關機，省電也省錢。
買賣的時候，系統會用 Telegram 手機簡訊通知你——你不用一直盯著螢幕。
你可以自行設定要買賣的個股、策略和資金。不用寫程式，但我建議你至少看得懂 Python，這樣以後要調整參數會比較方便。
系統內建五組策略，另外預留四組讓你自己定義。回測資料方面，可以調用 Finmind 和 TWSE 的歷史股市資料——這些都是免費的。
下單的部分，目前使用玉山證券的 API，之後你也可以自行換成其他券商的 API。
最後，我們會給你一份完整的 WSL 壓縮檔，所有 Python、DSH 等工具都已經安裝好了，打開就能用。

**講師提示**：這頁資訊量大，可以搭配畫面逐條指著講；提到 00632R 時可略作說明它是反向 ETF 範例。

## slide-10 deepseek-flash（2 分鐘）

接下來這個例子很重要，讓大家看看怎麼「跟 AI 討論策略」。
我問 DSH：我預期某檔股票——我們姑且叫它 XX——股價還會上升，該用什麼策略？
AI 分析後指出：XX 是「結構性利多」加上「循環股標籤」的混合體。結構性利多讓它有向上空間，循環股標籤讓它波動極大。所以策略要同時兼顧這兩者。
它給了我四個方向：第一，核心部位加移動停利——大部分持倉抱緊吃主升段，但跌破季線或月線就減碼；第二，盯著毛利率和庫存轉折——Q1 毛利率 38%，是記憶體模組廠的史詩級數字，要小心的是毛利率連續兩季下滑、DRAM 合約價漲幅收斂、存貨週轉天數攀升這些訊號；第三，分批出場——循環股的鐵律是不要妄想賣在最高點，300、400、500 每過一個關卡出二到三成；第四，想清楚不利情境——漲多修正、市場重新定性，這些風險要先有心理準備。

**講師提示**：這頁是「AI 能當策略軍師」的示範，講解時可以放慢，讓學員消化 AI 的推理邏輯。

## slide-11 deepseek-flash（2 分鐘）

我接著問 AI：那「250 以下買、280 以上賣」可以嗎？
AI 先幫我檢查數字——它說目前股價 233，本來就已經在 250 以下，所以現在就是買點。
問題在 280 就賣：XX 光是 Q1 EPS 就 27 元，就算後面三季保守估 30 元，全年 EPS 也有大約 57 元。280 賣掉，本益比不到五倍。如果這波真的是結構性超級景氣，市場重新評價到八到十倍本益比，股價可以到 450 到 570 元——現在 280 就賣，等於賣在剛起漲的位置。
所以 AI 建議：買的條件沒問題，但賣的條件要更動態——第一目標 300 出三分之一、第二目標 400 再出三分之一，留一部分看景氣能走到哪裡。
最後我要強調兩件事：第一，這是在 DSH 中的 AI 問答，不是一般對話型 AI——DSH 會先掃描專案內所有檔案，才能針對這個專案回答；第二，AI 說的不全對，但是很有參考價值。這是我們面對 AI 建議該有的心態。

**講師提示**：這頁是全場重點，可以放慢到 2.5 分鐘。最後那句「AI 說的不全對，但很有參考價值」是這堂課的態度宣示，務必講清楚。

## slide-14 怎樣申請Gcloud雲端主機-1 名稱為 tw-self（3 分鐘）

接下來是今天的重頭戲：怎麼申請一台 Google Cloud 雲端主機。我會照著畫面一步一步帶大家做。
這台機器我們取名為 tw-selfselect（名稱可自取；本機 .env 的 SYNC_VM_NAME 要填同名），規格是：位置在 asia-east1-b，也就是台灣彰濱工業區的機房，對台灣使用者來說連線速度最快；機型是 e2-micro，一核心 vCPU、1GB 記憶體；作業系統用 ubuntu-2204-jammy。
第一步，註冊 Google Cloud 帳戶並開通免費試用：用你的 Google 帳戶登入官網，點「免費開始使用」，填基本資料、綁定一張信用卡或金融卡。
不用擔心，Google 綁定信用卡主要是驗證真人身份，在你手動升級為付費帳戶之前不會自動扣款。註冊成功通常會拿到 300 美元的免費試用額度，限期 90 天。
第二步，建立新專案：進到控制台，點「新建專案」，取個名字，比如 my-trader-project。

**講師提示**：操作型頁面，建議邊講邊示範，或請學員跟著操作；學員卡關就停下來等。

## slide-15 怎樣申請Gcloud雲端主機-2（3 分鐘）

第三步，建立跟圖片一模一樣的 VM 虛擬機器。
點左上角導覽選單，找到 Compute Engine，選「VM 執行個體」。第一次使用會提示啟用 Compute Engine API，點啟用，等幾分鐘。
接著點「建立執行個體」，照著規格設定：名稱輸入 tw-selfselect（可自取，需與 .env 的 SYNC_VM_NAME 一致）；區域選 asia-east1，可用區選 asia-east1-b；機器組態選 E2 系列、e2-micro 類型；開機磁碟點「變更」，作業系統選 Ubuntu、版本選 22.04 LTS。
防火牆的部分：如果這台機器未來要架網站或對外連線，就勾選「允許 HTTP 流量」和「允許 HTTPS 流量」。
確認右側預估費用後，點「建立」。建立完成後，你就能在列表看到這台機器在運行，透過「SSH」按鈕就能連進去操作。

**講師提示**：建議提醒學員：規格必須跟圖片一致，不要自己升級，省錢是這堂課的重點。

## slide-16 快速設定靜態IP步驟（將現有 IP 轉為靜態）（2 分鐘）

機器建好之後，還有一個關鍵動作：把 IP 轉成靜態。
為什麼要這樣做？因為預設的 IP 是暫時的——機器重啟或關機後就可能變動。但玉山證券 API 需要設定白名單，IP 一變就麻煩了。
步驟如下：進到 GCP 控制台，點導覽選單，找到「VPC 網路」裡的「IP 位址」。你會看到一筆分配給 tw-selfselect 的 IP，類型顯示「外網／暫時」。點右側的三個點，選「保留靜態外部 IP 位址」，取個名字，比如 tw-selfselect-static-ip，然後點「保留」。
請把這個 IP 記錄下來——等一下申請玉山 API 的時候，要拿它去設白名單。設定完成後，類型會變成「靜態」，以後不管機器怎麼重啟關機，IP 都不會變了。

**講師提示**：強調「記錄 IP」這個動作，學員最常在這裡漏掉。
